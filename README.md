# Fellowship Recruitment Cross-Check

Cross-references six years of fellowship application data (2020–2026) against the
university listserv and its reply history, to see which university contacts are
producing applicants and which have gone quiet.

## Live report

**[Recruitment Signal Report](https://claude.ai/code/artifact/de3cf869-d821-4b70-9807-aa3944d7fc0e)**

Where applicants actually come from, which university contacts are silently
forwarding the call despite never replying, which confirmed they're forwarding it,
and which are producing nothing — broken down to the department/mailing-list level.

## Files

- `University_Recruitment_Cross_Check.xlsx` — the full cross-referenced workbook
  (university × cycle summary, raw applicant records, unmatched-institution review
  list, department-level reply detail)
- `cleaned_listserv.xlsx` — university contact list
- `fellowship_replies.xlsx` — reply-cycle classification data (Dec 2025–Apr 2026)
- `*Fellow Evaluation*/` — per-cycle application evaluation workbooks and applicant
  documents, by year
